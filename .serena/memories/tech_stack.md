# Technology Stack

## Backend Framework
- **Django 5.2.1** - Main web framework
- **Python** - Programming language

## Database
- **MySQL** - Primary database (configured for production)
- **mysqlclient 2.2.7** - MySQL database adapter
- Database name: `curhub_db`
- UTF-8 (utf8mb4) charset for Vietnamese language support

## Frontend Technologies
- **HTML Templates** - Django template system
- **Bootstrap 5** - CSS framework (via crispy-bootstrap5)
- **AdminLTE** - Admin dashboard theme (extensive plugin collection in static/adminlte/)
- **JavaScript** - Client-side functionality

## Key Dependencies
- **crispy-forms & crispy-bootstrap5** - Form rendering
- **asgiref 3.8.1** - ASGI utilities
- **sqlparse 0.5.3** - SQL parsing
- **tzdata 2025.2** - Timezone data

## Development Environment
- **Windows** - Target development platform
- **MySQL Server** - Database server
- **Django Development Server** - For local development

## Static Files
Extensive AdminLTE plugin collection including:
- DataTables, Chart.js, Select2, Bootstrap components
- Form validation, date pickers, file uploads
- UI components and themes
